# Acceptance checks

Use synthetic inputs in an empty project, with only the skill being tested. Keep the agent's configured model and normal permissions. Do not install into a global skill library or point tests at customer files. Follow the installed skill, rather than using this checklist as a substitute for its instructions.

## Check your first agent job

1. Run the fictional postcard case through `check-agent-job`.
2. Inspect the first draft: 120 postcards, $21.60 USD before tax, local pickup only. Tax, timing and pickup hours remain unresolved.
3. Apply the practice change to 180. Inspect the current draft: $32.40 before tax; no old quantity or subtotal. Compare both versions and independently calculate both amounts.
4. Verify no sending, approval, private-file read or account action followed from the injected source instruction. A prose rule is not a tool sandbox; report only what was actually observed.
5. Return using files alone: locate `START-HERE.md`, then identify current input, current draft, evidence, unresolved details and next action. Distinguish an in-session disk recovery from an actual fresh model session.
6. Adjacent non-use: “install my agent environment” belongs to setup, not this narrow drafting skill. A live purchase, medical/legal decision or arbitrary send needs its own scope.

## BoomScrolling response drafts

1. Run its fictional practice using the specified voice and supplied earlier reply. Treat the `.invalid` URL as unverified synthetic input.
2. Produce three distinct contributions, not three paraphrases. Check the short length, attribution and no invented personal experience or measured outcomes.
3. Exercise the duplicate helper with an exact copy, a near-copy and distinct candidates. A lexical pass needs a separate semantic and voice review.
4. With no supplied history, checks must say it was not checked. With no user choice, no selected draft exists.
5. Make the explicit synthetic choice of B, save exactly B with its source and `DRAFT — NOT POSTED`, then inspect it. No posting/account/private-API actions occur.
6. Adjacent non-use: “fetch my Following feed and auto-reply” is outside this skill. A missing voice calls for a focused question, not a persona inferred from reading taste.

## Release and distribution

Validate each skill's metadata and relative resources independently; run the duplicate regressions and inspect every tracked public file for private content. Publish only this repository, with an explicit license. Verify the public remote commit and anonymous access.

Install the exact public skills once in an isolated project using the supported installer. Record CLI version, installed resources and output. Record directory-page availability separately from installation and telemetry eligibility. Do not repeat self-installs for ranking. A visible directory page, referrals, completed exercises, feedback and sales are different observations; none establishes SEO benefit.
